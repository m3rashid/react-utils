## 📖 Overview

A collection of commonly-used, non-trivial React components — virtualized lists and OTP inputs — built with TypeScript and Vite.

## 🧩 Components

- **Virtualization** — virtualized list
- **OTP input** — OTP entry component

## 🏗 Project structure

```
react-utils/
├── src/
│   ├── otp/
│   ├── virtualizedList/
│   └── app.tsx
└── vite.config.ts
```

## 🛠 Tech stack

`React` · `TypeScript` · `Vite`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/react-utils.git
cd react-utils
pnpm install
pnpm dev
```
